0.005_260829
  - Rebuilt on ncurses. Resizable window, scrollable view with line
    numbers, status bar (filename + last change time), and a command
    line for "q" to quit or a line number to jump to.
  - Dropped the Boost dependency; file-change detection now uses
    plain POSIX stat().
  - Long lines wrap onto extra screen rows instead of being cut off
    at the right edge.
  - Fixed misaligned wrapping/gutter on lines with multi-byte UTF-8
    characters (emoji, accented letters, etc.) - the program never
    called setlocale(), so ncursesw and the wrap logic were treating
    those bytes as plain 1-byte-per-column ASCII.
